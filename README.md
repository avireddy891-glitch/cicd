## 📌 Project Overview

The **Home Automation System** is a web-based application designed to monitor and control home devices through a centralized dashboard.

The project is integrated with **GitHub and Jenkins** to implement a Continuous Integration and Continuous Delivery (CI/CD) workflow.

Whenever changes are pushed to the GitHub repository, Jenkins automatically detects the changes, builds the project, performs testing, and deploys the application.

## 🚀 Features

- 🏠 Home automation dashboard
- 💡 Device monitoring and control
- 📊 Centralized web interface
- 🔄 GitHub version control
- 🔀 GitHub Pull Requests
- ⚙️ Jenkins CI/CD pipeline
- 🤖 Automatic build triggering
- 🧪 Automated testing stage
- 🚀 Automated deployment stage
